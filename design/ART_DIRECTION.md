# 溪谷镇 · 美术方向（ART_DIRECTION）

> 输入：[design/GAME_DESIGN.md](GAME_DESIGN.md)。输出：一套可执行的视觉决策，供 build 与 qa 引用。
> 状态：v1，已实装于 `src/render.js`（Canvas 2D），未使用任何外部美术资源。

## 1. targetFinish

**一句话**：一座被晒得有点发灰的小镇，人是画面里唯一鲜艳的东西。

- **finished look**：俯视、正交、无透视缩放；软边矢量色块（不是像素画），低分辨率诚实感来自 26px 网格和手绘感的不规则轮廓，而不是像素点阵。
- **质感**：干、哑、有尘土。草地饱和但明度低，路面是旧石板被踩出的浅色带，屋顶是褪色的赭红。
- **镜头**：固定俯视，40×30 格整幅可见，无滚动、无缩放、无旋转。玩家永远看得见整个镇子——这是"这是他们的世界，我只是在场"的表达手段。
- **不是**：不是星露谷那种高饱和、高对比、每格都在闪的农场；不是像素画；不是等距斜视；不是 UI 贴满屏幕的模拟经营。

## 2. 视觉原则（按优先级）

1. **人是唯一的高饱和**。地形与建筑统一压到 45–55% 饱和度；八个居民各有一个身份色（阿岚 `#8fc45f`、老墨 `#8a6d47`、阿梨 `#d98cc0`、苏叶 `#dfeae5`、小满 `#e0b05a`、青禾 `#9fc9e8`、石头 `#c3cbdc`、铁牛 `#cf7f4f`），衣服之外的地方不出现这些颜色。
2. **剪影先于细节**。每个人物在 26px 格里只有约 14×16 px，所以识别靠三件事：体型椭圆 + 1px 深色描边（`rgba(24,30,24,.38)`）+ 一件职业道具（草帽、锤子、白大褂和红十字、贝雷帽和画笔、围裙、鱼竿和鱼线、护肩和长矛、挎包和硬币）。
3. **不把状态贴在头上**。禁止血条、禁止等级、禁止悬浮图标堆。状态用姿态（走路有 bob、睡觉有 zzz 位）、气泡、以及需求极低时的单个字（饿/困/聊）表达。
4. **克制的暗**。夜晚不是加一层黑，而是把环境压到 `#0d1420` 的蓝黑，只留路灯与窗户的暖光（`#f2ce86`）作为唯一光源。夜里能看清路，看不清人。
5. **UI 是纸，不是玻璃**。面板底色 `#14171c`，分隔线极弱，强调色只有一个金色 `#e0b05a`。所有中文标签 11–13px，不用大写英文标签。

## 3. 镜头与视觉语法

| 层 | 画法 | 目的 |
| --- | --- | --- |
| 地形 | 4 色抖动 + 4×3 大尺度明暗斑 + 草簇 | 整片草地不呆板，但不抢注意力 |
| 路径 | 双排错缝石板，边缘色偏亮 | 主街是唯一的动线，视觉上必须一眼看出 |
| 水面 | 深蓝 + 两道波纹 + 浅色岸线 | 池塘是地标，不是障碍物 |
| 建筑 | 俯视剖切：地板 + 墙框 + 屋顶带 + 屋脊高光 + 两扇窗 + 门框踏脚 | 一眼看出这是"能进去的房子"，且能看出里面有没有人 |
| 家具 | 每类建筑一个锚点（床/吧台/药柜+十字/画架/长桌/木料） | 房子不是空盒子，职业在这里发生 |
| 作物 | 按生长阶段换高度与颜色 | 农活有可见的进度 |
| 人物 | 腿 + 身体 + 头 + 头发 + 双眼 + 道具 | 14px 内可辨 |
| 天气 | 雨：斜线与涟漪；风：旋转叶片；阴：移动云影 | 天气是氛围，不影响判读 |
| 夜间 | 渐变暗 + 路灯/窗户径向暖光 + 呼吸脉动 | 时间感 |
| 覆盖层 | 悬停格、放置预览、悬停卡片 | 交互反馈 |

## 4. HUD 与反馈

- **顶栏**：日期时间、天气、速度（暂停/1×/2×/4×/8×）。只此一行。
- **右栏三个页签**：世界（统计与仓库与建造）、居民（名单与完整档案）、日志（可筛选，重复行折叠为 `×N`）。
- **悬停**：显示姓名·职业 / 当前目标 / 心情值，金色描边小卡；被悬停的人自己的气泡让位给卡片。
- **气泡**：白纸质感（`rgba(250,247,240,.96)`），最多三行，贴边自动收窄，左右相邻的人按 id 错开三档高度，避免叠字。
- **对话弹窗**：头像色块 + 姓名 + 状态行 + 一句台词 + 可选第二拍（追问或传闻）+ 秘密揭示。
- **浮动文字**：只在"获得/失去/情绪"时出现，字号小、寿命短（60 刻），不累积。

## 5. 关键游戏时刻（视觉必须服务这些瞬间）

1. **第一次有人主动跟你说话**——你还没点他，气泡先出来。这一下决定"他们是不是活的"。
2. **你放下图纸，木匠改了自己的计划走过来**——图纸是虚线的金色轮廓，建成的一瞬间出现木屑浮动文字与一条日志。
3. **夜里路灯亮起**——环境暗下去，暖光亮起来，剩下的人在窗口。
4. **信任够了，秘密被说出来**——弹窗里多出一行，日志标为 drama，颜色变金。
5. **两个人吵架**——两个气泡、一个"怒"字浮动、日志一条，旁人不参与。

## 6. 资产清单

**必需（已具备）**：12 栋建筑的剖切图、8 个居民（每人 1 套造型 + 1 件道具）、4 种装饰（长椅/花圃/喷泉/路灯）、作物 3 阶段、4 种天气、昼夜两层光。

**可降级**：所有图形都是画布绘制，没有位图依赖；若性能不足，可关闭大尺度明暗斑与草簇（`drawTiles` 内两处开关），不影响判读。

**明确不做**：立绘、过场动画、粒子系统、着色器后处理、3D。理由见 GAME_DESIGN 的"不做"清单。

## 7. 未定与风险

| 风险 | 说明 | 当前处置 |
| --- | --- | --- |
| 分辨率 | 1040×780 画布被 CSS 缩到约 822×617（0.79×），12px 画布内文字实际约 9.5px | 已把画布内最小字号提到 10.5px；若后续要更清晰，改成 DOM 覆盖层而不是加大画布 |
| 密集场景 | 多人同格时气泡仍可能重叠 | 已按 id 三档错位 + 悬停让位；超过 3 人同格属未解决 |
| 无音效 | 没有环境音与动作音，情绪全靠画面 | 记入 BUILD_BRIEF.limitations；音频是下一个表现层缺口 |
| 手绘感上限 | 纯几何绘制缺少笔触 | 接受。用色与构图补，不追像素或手绘 |
| 窄屏 | 820px 以下右栏会挤压画布 | 未适配，P0 待办 |

## 第七轮落地：开罗式的像素语言 + 羊皮纸界面

这一轮把「风格」变成了可执行的规则，全部写在 `src/art.js`。

### 画布语言

- **像素块 = 2px**：所有矩形、描边、圆角都吸附到 2 的倍数，缩到 0.79 倍时不会糊边。
- **一切都有墨线**：人、房子、木牌、按钮都带 2px `#3b2a1f` 描边——这是开罗可读性的来源，不是装饰。
- **暖色六色**：草 `#8abd5f/90c265/85b659`、土路 `#dcb689`、水 `#4f92c6`、木 `#a9743f`、墙 `#f4e5c6`、瓦 `#c25a44/5b8f8a/7a6f9c`。
- **每格有微差**：草用 3×3 大块底色 + 哈希草簇；路用跨格碎石，不出现方格接缝；水有岸线泡沫。

### 建筑

屋顶占 55%，梯形 + 瓦行 + 屋脊高光 + 2px 墨线；墙体奶白 + 木板横线；门带门框、把手、踏脚石；两扇窗，夜里透 `#f7d795` 并带径向光晕；屋前挂木牌写名字。

### 居民

16×22 的 Q 版小人：大头、粗描边、两帧走路、按性别/职业换衣色，职业道具（草帽 / 贝雷帽 / 白大褂 + 红十字 / 围裙 + 锤 / 鱼竿 / 护肩 / 挎包）。悬停有金色光环，选中更亮。

### 界面

羊皮纸：底 `#f0e2c6` 斜纹、面板 `#fbf3df`、边框 `#d3bb93`、文字 `#4a3826`、按钮有 `0 2px 0` 的硬阴影。画布嵌在一圈木框里（`0 0 0 4px #c9a97a`），像摆在一块木板上。

### 还没做到的

- 没有逐帧动画表：走路只有两帧上下浮动，没有挥手、坐下、吃饭的动作。
- ~~没有季节换色~~（第 11 轮已做：见下节）
- 没有开罗那种「建筑升级换皮」：房子建成后外观不变。

### 第十一轮落地：四季调色板

- 7 天一个季节，28 天一轮。只换色，不改形状——轮廓与布局在任何季节都保持稳定。
- 草地：春嫩绿、夏深绿、秋金黄、冬霜灰（`art.js` 的 `GRASS_SEASON`，含 base/light/dark/tuft/spark/edge/shore 七个槽位）。
- 树冠：春绿、夏深、秋橙金、冬灰霜（`TREE_SEASON`）。
- 换色的依据是 `sim.clock.season`，渲染每帧现取，不进存档、不改寻路。
