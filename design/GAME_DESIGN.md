# 溪谷镇 · GAME_DESIGN

> 一句话：一座八个人的小镇，他们有自己的日子；你能看、能插话、能改街景，
> 但不能替他们活。

版本：原型 v0.1（可运行白盒，内容层 8 人 / 12 栋 / 4 种装饰）
配套：[NPC_AI_ARCHITECTURE.md](../docs/NPC_AI_ARCHITECTURE.md)、[ROADMAP.md](../docs/ROADMAP.md)

---

## 1. 玩家承诺

**不是"经营一座镇"，而是"被一群有自己主意的人记住"。**

三条承诺，按优先级：

1. **他们是活的**：每个居民在任意时刻都有一件正在做的事和一句正在想的话；
   你不动，镇子照样运转，而且第二天会不一样。
2. **他们记得你**：你说过的话、送过的礼、听过的秘密会进入他们的记忆和关系网，
   并且会通过闲话流到第三个人耳朵里。
3. **你能改变形状，改不了人心**：图纸、街景、美观度是你能直接施加的力量；
   人的态度只能靠时间和互动慢慢换。

反面承诺（明确不做）：不做全知视角的上帝模拟，不做刷数值的最优解，不做
"每个 NPC 都等着玩家触发"的木偶戏。

## 2. 玩家幻想与情绪曲线

| 阶段 | 玩家在想什么 | 游戏给的证据 |
| --- | --- | --- |
| 第 1 小时 | "这帮人真的在自己动？" | 打开阿岚档案，看到"去上工·在路上"，两分钟后她真的在田里浇水 |
| 第 2–3 小时 | "我好像摸到谁跟谁不对付" | 日志里"阿梨和苏叶话不投机"，两人关系条一个高一个低 |
| 第 4 小时+ | "我说的话会传出去" | 你把阿岚的秘密告诉老墨，第二天石头从老墨那里听说了 |
| 长线 | "这条街是我改的" | 你在空地上放了长椅和路灯，木匠来施工，街区美观 6→9 |

情绪基调：安静、日常、有毛边。冲突是低烈度的（拌嘴、藏心事、欠人情），
不是战斗，也不是灾难。

## 3. 核心循环

### 3.1 分钟级（玩家动作）

```
观察（点开档案 / 看日志）
   → 判断（谁现在有空、谁心情差、仓库缺什么）
   → 干预（走过去聊两句 / 送个礼 / 放下图纸）
   → 读反馈（对话台词、需求条、日志一行、地图上的漂浮字）
```

单次循环 20–60 秒，必须有即时反馈。任何干预都要在 1 秒内给出可见回应：
一句台词、一个数字变化、一条日志。

### 3.2 小时级（NPC 的一天）

```
需求漂移 → 目标打分 → 选计划（多步）→ 寻路 → 执行动作 → 结算（资源/心情/记忆/关系）
                ↑                                              ↓
                └────────── 计划失败或需求突变时重新决策 ←────────┘
```

一天里有四个自然段落：

- **06:00–11:00** 起床、吃饭、上工。农田有作物时农夫最忙，木匠看有没有图纸。
- **11:00–14:00** 午间。酒馆开门，社交需求高的人聚过来。
- **14:00–19:00** 下午班。玩家干预成功率最高（大部分人在户外）。
- **19:00–23:00** 夜间。灯光亮起，聊天、散步、喝酒；23:00 后陆续回家睡觉。

### 3.3 天级（镇子）

```
换日 → 天气刷新 → 作物生长/枯萎 → 树木与资源结算 → 新的一天
```

玩家感知到的天级变化：天气、街景（新长椅）、作物状态、谁跟谁更熟了。
天级不需要玩家操作，只需要玩家**注意到**。

## 4. 世界如何回应

这是本项目最重要的设计表：每一条都必须有实现或明确标注为未实现。

| 玩家行为 | 世界回应 | 状态 |
| --- | --- | --- |
| 走过去和某人说话 | 对方按当下状态给一句台词（忙 / 闲 / 心情差 / 熟悉度够则吐露秘密） | 已实现 |
| 送礼（5 硬币） | 好感 +7，写入记忆，关系标签变化 | 已实现 |
| 反复找同一个人 | 熟悉度累积，第 3 次左右开始说心事 | 已实现 |
| 放下图纸 | 扣仓库资源，木匠改计划来施工，建成后美观度上升 | 已实现 |
| 砍光林子 | 木匠没树可砍，回工坊做木工；木材供给变慢 | 已实现（间接） |
| 夜里在街上晃 | NPC 陆续回家，路灯亮，视野变暗 | 已实现 |
| 在酒馆门口堵人 | 酒馆 8–23 点营业，食物耗尽会打烊并补货 | 已实现 |
| 长时间不出现 | 镇子照常运转，关系和秘密自己演化 | 已实现 |
| 让某人饿着 | 需求低于阈值 → 计划被打断，紧急图标出现，心情下滑 | 已实现 |
| 建一堆喷泉 | 美观度上升，居民心情随之上升（基准 6） | 已实现 |

原则：**回应的优先级是"人 > 物 > 数"**。同一件事，先让 NPC 有反应（计划变化），
再让场景有反应（建造/破坏），最后才是数字（美观度、心情均值）。

## 5. NPC 设计

### 5.1 四层结构

| 层 | 内容 | 变不变 |
| --- | --- | --- |
| 性格（traits） | 18 种，两两组合，转成乘区系数 | 固定 |
| 价值观（values） | 3–4 个词，如"土地/体面/承诺" | 固定 |
| 需求（needs） | 饥饿、精力、社交、乐趣、成就，0–100 | 每刻漂移 |
| 状态（state） | 心情、记忆、关系、信念、当前计划 | 持续变化 |

**设计取舍**：不做性格数值面板（"勤劳 7/10"），只给 2–3 个形容词 chip。
玩家应该记住"阿岚是个嘴硬心软的人"，而不是"阿岚勤劳 8 固执 7"。

### 5.2 八个人的差异化重点

| 居民 | 职业 | 一句话 | 戏剧功能 |
| --- | --- | --- | --- |
| 阿岚 | 农夫 | 三代务农，父亲留下的地在河塘东侧 | 土地与债务的重量；第一个会跟你说心事的人 |
| 老墨 | 木匠 | 手上有活就踏实 | 建造系统的执行者；沉默但记仇 |
| 阿梨 | 画家 | 画卖不出去，但每天还在画 | 理想与现实的摩擦；最容易被闲话伤到 |
| 苏叶 | 医生 | 谁的事她都管，自己的事不说 | 秘密的集散中心 |
| 小满 | 酒馆老板 | 全镇的耳朵 | 信息枢纽；对谁都客气，对谁都不亲 |
| 青禾 | 渔夫 | 话少，看着水面 | 低社交高观察；知道最多但最少说 |
| 石头 | 守卫 | 认死理 | 规则与人情的冲突点 |
| 铁牛 | 商人 | 什么都卖，包括消息 | 经济与流言的交叉口 |

每人都写了：`bio`（来历）、`desire`（渴望）、`fear`（害怕）、`secret`（秘密）、
`values`、`skills`、`home`、`work`、`coins`、`traits`。秘密是关系系统的燃料，
不是收集品——只有信任够高才会吐露，而且会顺着闲话传出去。

### 5.3 一个 NPC 的一天长什么样（阿岚，第 2 天）

```
06:10 醒，饿了 → 目标 eat 得分最高 → 去酒馆买饭（或吃随身干粮）
07:05 成就需求上来 → 目标 work → 计划：走到田里 → 浇水 → 收割
09:30 社交掉到 40 以下，且阿梨在附近 → 目标 social → 走过去闲聊
11:20 计划完成，重新打分 → 继续 work（作物没熟就照料）
12:40 精力 35，饥饿 30 → eat 插队，饭后又回田里
18:50 太阳低了 → relax 得分上升 → 去长椅坐着发呆
21:30 社交又掉 → 去酒馆；小满在，两人聊了几句，关系 +2
22:40 精力见底 → sleep → 回家，睡到 06:00
```

这不是脚本，是打分＋计划的结果。改一个系数，这一天的形状就会变。

## 7. 经济与资源

- 起始公共仓库：木 26 / 石 9 / 食 14 / 种 12 / 钱 90；玩家 80 硬币。
- 收入：农夫收割（食物）、木匠砍树（木材）、酒馆卖饭（钱）、诊所看病（钱）。
- 支出：吃饭 6 硬币/次、送礼 5 硬币、建造扣仓库材料。
- 通胀控制：木匠每天最多砍 3 棵，且只在木材 <32 时砍；酒馆断粮时会花 12 硬币
  补 6 份食材（带冷却），避免"永远缺货"或"无限刷钱"。

设计意图：经济是**节拍器**，不是挑战。它决定"今天镇子缺什么"，从而决定 NPC
今天的行为分布，进而决定玩家看到什么。

## 8. 反馈层

| 通道 | 用法 | 例子 |
| --- | --- | --- |
| 地图 | 谁在哪、在干什么 | 头顶想法气泡、紧急图标（饿/困/想聊） |
| 档案 | 完整状态 | 需求条、当前计划与步骤、关系网、记忆 |
| 日志 | 时间线叙事 | "老墨和阿岚闲聊了几句" |
| 漂浮字 | 即时情绪 | 聊、心、怒、秘 |
| 数字 | 只给结论 | 心情 46、美观 6 |

**克制原则**：地图上不出现血条式数字；数字只在侧边栏出现。让玩家用眼睛读人，
而不是读数值。

## 9. 失败与压力

没有 Game Over。压力来自三处：

1. **错过**：你不在的时候，秘密被别人先听到了。
2. **关系不可逆的钝化**：吵架后好感会掉，恢复要靠多次互动。
3. **资源错配**：把木材都花在路灯上，木匠就没材料修房子（后续版本会加房屋损耗）。

原型阶段这三条都只是**弱压力**，符合"日常模拟"的基调。

---

## 10. 原型范围与验收

本版要证明的三件事：

1. 八个人能在无人干预下跑满 7 天，数值不发散（无头自检 10/10 通过）。
2. NPC 的行为能被玩家看懂：任意时刻点开任何人，都能说清"他在干什么、为什么"。
3. 玩家的干预能改变世界：图纸 → 建造 → 街景与美观度变化。

不追求的：美术精度、音效、内容量、平衡性长线。

## 11. 后续设计悬而未决的问题

1. ~~NPC 该不该主动找玩家？~~ 已实现：距离 ≤2.3 且好感 ≥26 时主动开口，220–360 刻节流。
2. **秘密被公开后的后果**：现在只有一条日志，应该有关系链式反应。
3. **玩家自宅与种植**：星露谷的核心循环，本版缺失，是下一步最大的内容缺口。
4. ~~美观度要不要影响 NPC 心情~~ 已实现：`clamp((beauty-6)*0.9, -8, 8)` 进心情公式。
5. **失败体验**：需要至少一种"你真的搞砸了"的情形，否则干预没有重量。
