# 溪谷镇

**在线试玩：https://dongshg3.github.io/xigu-town/**

**接手开发先读：[HANDOFF.md](HANDOFF.md)** —— 架构、接口、坑、验收标准、下一步任务。
 · NPC 生活模拟原型

一款 2D 角色扮演 + 模拟经营原型：你是一个刚搬进溪谷镇的旅人，八位居民各自有
欲望、恐惧、秘密、性格和作息，会自己决定去干活、吃饭、串门、吵架、传闲话、
向信任的人吐露心事——也会因为你在镇上放下的图纸，真的动手把它建起来。

参考作品的气质：《星露谷物语》的日常与建设 + 《环世界》的个体需求与自主行为 +
开罗游戏的轻量经营循环。区别在于：这里的重点不是数值最优，而是**把 NPC 的一天
演给你看，并且让你能插一脚**。

## 运行

```bash
node server.mjs          # 默认 http://localhost:5173
npm run dev              # 同上
npm run smoke            # 无头跑 7 天模拟 + 14 项断言（不开浏览器）
npm run verify           # 无头 Chrome 六项证据化验收，写 qa/verification.json
```

要求：Node 18+（验收需要本机有 Chrome 或 Edge，可用 `CHROME_PATH` 指定）。
零依赖、零打包，原生 ES module + Canvas。

## 操作

| 操作 | 说明 |
| --- | --- |
| 点击地面 | 旅人走过去 |
| 点击居民 | 打开完整档案（秘密、记忆、关系、当前计划） |
| 鼠标悬停居民 | 小卡显示姓名·职业 / 当前目标 / 心情，不必点开 |
| 空格 | 暂停 / 继续 |
| 1 / 2 / 4 / 8 | 切换时间倍速 |
| P | 显示所有 NPC 的当前计划 |
| Esc | 取消放置图纸 |
| Ctrl+S / Ctrl+L | 存档 / 读档（localStorage） |

侧边栏三个页签：

- **世界**：镇子统计、公共仓库、改造环境（长椅 / 花圃 / 喷泉 / 路灯），放下图纸后
  木匠老墨会自己来施工，木材石料从公共仓库扣。
- **居民**：八人卡片 → 点开是完整档案。交谈、送礼都在档案页里。
- **日志**：镇日志，可按社交 / 事件 / 劳作 / 建造 / 世界筛选；重复行折叠成 `×N`。

## NPC 的“智能”是怎么来的

- **台词是算出来的，不是选出来的**：每次开口，先从当前世界（天气、库存、需求、关系、
  记忆、传闻）里抽出几条真实事实，再选一个意图（抱怨 / 分享 / 提问 / 干活 / 亲近 /
  观察），再用这个人自己的句式说出来；最后和最近 16 句做相似度比较，挑最不像的。
  所以同一句话不会出现两次，而同一个事实换个心情会换一种说法。
- **每个人都在学**：哪类谈话能换来好感（policy）、哪些话题对方有反应（topics）、
  哪个目标比预期更解渴（habits）、这几天整体过得好不好（moodBase）。学习结果直接
  改写后面的决策权重与开口倾向，并且随存档保存。
- **可选接模型**：侧边栏「世界 → 语言模型（可选）」填任意 OpenAI 兼容端点，模型只
  负责把本地那句改写成这个人的口吻；超时、报错、说得不像话都保留本地那句。

## 这一版能做什么

| 系统 | 玩家能做的事 |
| --- | --- |
| 生活 | 点地面走动，点居民看档案，站着看他们自己过日子 |
| 对话 | 详情页输入框自由打字，NPC 按人设、心情、记忆现场生成回答；也可以只点「交谈」 |
| 建造 | 从「世界」页放下长椅/花圃/喷泉/路灯/新居，木匠会来盖 |
| 经济 | 市集买卖、接委托交货、酒馆吃饭、打零工（8:00–18:00，24 刻冷却） |
| 政治 | 看议会与镇长、投票、推提案（开放土地/降税/加税修设施）、声望 ≥40 可参选镇长 |
| 版图 | 购地扩张、盖新居、移民搬入成为第 9、第 10 个居民 |
| 记忆 | 每条记忆带话题，居民会记住你问过什么，传闻会在居民之间扩散并改变他们爱聊什么 |

## 部署（GitHub Pages）

纯静态、相对路径，可直接由仓库根目录托管：

1. 仓库根目录放 `.nojekyll`（已就绪），`index.html` 在根。
2. Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`。
3. 不需要构建、不需要 `node_modules`、不需要任何环境变量。

本地验证等价性：`node server.mjs` 与 Pages 提供的是同一批文件，路径全部相对。
